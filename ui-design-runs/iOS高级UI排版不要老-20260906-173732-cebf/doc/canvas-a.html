01

我们怎么理解这件事

"iOS 高级 UI 排版"不是把字号调大、把圆角改圆。它是让文字本身成为界面的主角—— 在一个 390×844 的有限空间里，用字号的断崖、留白的呼吸、色域的切换， 让用户在拇指滑动的三秒内感受到"这不是又一个内容 App"。

我们观察了 App Store 中排名前 50 的内容类应用，发现一个系统性问题： 绝大多数产品停留在"卡片墙"阶段——等宽卡片、统一圆角、系统默认图标、 标题只是"大一点的正文"。这种排版在 2018 年是合格的，在 2026 年就是"老旧"。

真正的高级排版有三个特征：字号有断崖（标题不是正文的 1.2 倍，而是 1.8–2.5 倍）、 版面有节奏（不是每一段都长一个样，而是密—疏—密交替）、 文字有性格（展示字体与正文字体异质配对，不是全站一种字体走天下）。

核心判断

"老旧的排版"不是视觉风格问题，是信息层级问题—— 当所有内容被塞进等大的卡片里，用户的眼睛就失去了落脚点。

02

我们看到的机会

在内容类 App 普遍"卡片化"的当下，编辑体排版是一个被严重低估的差异化方向。 它不需要更多的功能、更复杂的交互，只需要重新安排文字的大小、位置和呼吸。

机会一
首屏即内容。不是"欢迎页 + 功能入口"，而是打开 App 第一眼就是一篇文章的标题和封面—— 让用户立刻知道"这里有东西值得读"。
机会二
编号列表替代卡片网格。用 01、02、03 的编号 + 非对称尺寸（第一条大、其余紧凑）， 既建立了阅读顺序，又打破了均匀网格的沉闷。
机会三
色域切换制造节奏。在连续的亮场内容中插入一段深色"热议区"， 用底色的突变告诉用户"这一段不一样"——比任何分割线都有效。
机会四
引用块作为换气点。在长列表中插入一段大字号引文， 既是内容的高光，也是视觉的休息站——用户的眼睛在这里"喘一口气"。

首屏特稿：满版氛围图 + 渐变暗场 + 衬线大标题叠加， 标题与图互锁，不是"图在上、字在下"的分离式排版。

03

设计主张

让排版先于功能说话。
打开 App 的第一秒，
用户就应该感受到阅读的仪式感。

这不是"为了好看而好看"——编辑体排版直接服务于内容消费的核心指标： 首屏停留时间、文章打开率、阅读完成度。当文字被认真对待，用户也会认真对待文字。

围绕这一主张，我们确立了四条不可妥协的设计原则：

原则一 · 字号断崖

展示标题25–27px
文章标题16.5–21px
正文15.5px
元信息11–12px

相邻层级 ≥1.3×，展示标题与正文 ≥1.6×。标题不是"大一点的正文"。

原则二 · 异质字对

Noto Serif SC展示/标题
系统无衬线UI/正文
SF Mono编号/元信息

衬线的文化感 + 无衬线的功能性 + 等宽的精确感，三种字体各司其职。

原则三 · 色域节奏

暖纸亮场~65% 面积
深暖棕场~20% 面积
焦土橙~3–5% 面积

亮场为主、深场换气、强调色只给 CTA 和编号。底色不是纯白，是有温度的纸。

原则四 · 非对称版面

首条大卡全宽图 + 大标题
紧凑条目编号 + 缩略图
纯文字条目无图，靠排版
引用块大字引文，无卡片

拒绝均匀卡片墙。每一种内容形态有自己的排法，版面因此有了呼吸。
