# 班主任工作台 - iOS 原生应用

基于 SwiftUI 开发的原生 iOS 班主任工作台应用，**100% 对齐网页版 UI 和功能**。

## 核心特性

- **底部 Tab 栏**：工作台、学生、成绩、我的（4个Tab）
- **工作台首页**：紫色渐变顶部 + 波浪底部 + 8个功能入口
- **学生管理**：按排筛选、橙色风格、电话按钮、#学号格式
- **成绩管理**：考试列表 → 成绩详情两级结构、新建考试、考试类型筛选
- **班级课表**：周视图网格、午休栏、星标标记我的课
- **值日表**：每天不同背景色卡片、成员标签
- **班级相册**：多相册分类、渐变封面、按日期分组
- **发通知/通知记录**：通知发布、置顶、未读标记
- **总分排名**：前三名展示 + 完整排名列表
- **我的页面**：个人信息、数据统计、设置入口
- **数据本地持久化**：所有数据存手机本地，自动保存
- **真实图片**：PhotosPicker 选图，存本地
- **真实地图**：MapKit 地图，学生家庭住址标记

## 页面结构

### Tab 1 - 工作台（首页）
- 紫色渐变顶部（问候语、工作台、班级名、日期）
- 3个数据概览卡片（班级学生、待录成绩、开设科目）
- 8个常用功能入口：学生名册、成绩管理、座位排布、发通知、班级课表、值日表、总分排名、通知记录
- 下周一值日（可切换下一组）
- 今日课程（我的课）
- 今日待办（可勾选、可添加）

### Tab 2 - 学生
- 顶部问候+班级+日期
- 搜索栏 + 打印按钮 + 添加按钮
- 按排筛选（全部、第1排-第5排）
- 学生卡片（橙色圆形头像、姓名、#学号、X排X座、电话按钮）
- 学生详情（基本信息、联系方式、地图位置、备注、编辑、删除）

### Tab 3 - 成绩
- 顶部问候+班级+日期
- 考试列表（学期选择、导入、科目、新建按钮）
- 考试类型筛选（全部、单元测、月考、期中考、期末考）
- 考试卡片（类型图标、考试名、科目数）
- 成绩详情（科目选择、统计、排序、成绩列表、录入）
- 新建考试（名称、类型、科目选择）

### Tab 4 - 我的
- 个人信息卡片（头像、姓名、班级）
- 数据统计（学生、考试、通知）
- 功能列表（设置、数据导出/导入、恢复示例数据、关于）

### 功能页面
- **座位排布**：7排×5列教室布局、讲台、小组颜色、快速排座
- **班级课表**：周视图网格、8节课、午休、科目颜色、星标我的课、图例
- **值日表**：本周值日安排、每天不同背景色、成员标签、周六周日无安排
- **分布地图**：MapKit 真实地图、学生住址标记、统计卡片
- **班级相册**：多相册列表、新建相册、渐变封面、按日期分组、照片详情
- **发通知**：标题、内容、接收范围、发布
- **通知记录**：通知列表、置顶、未读标记、详情、删除
- **总分排名**：考试选择、前三名展示、完整排名列表

## 数据模型

- `Student` - 学生（姓名、学号、性别、年龄、电话、家长电话、住址、小组、座位、宿舍、备注、经纬度）
- `Exam` - 考试（名称、类型、学期、日期、科目）
- `ScoreRecord` - 成绩记录（学生、科目、考试名称、分数、满分、排名、日期）
- `Course` - 课程（科目、星期、节次、时间、教室、老师）
- `DutyGroup` - 值日组（组号、成员、日期）
- `TodoItem` - 待办事项（标题、完成状态、优先级、关联信息）
- `AlbumFolder` - 相册分类（名称、分类、封面渐变、日期、置顶、照片ID列表）
- `AlbumPhoto` - 相册照片（标题、日期、描述、图片数据）
- `NotificationItem` - 通知（标题、内容、日期、接收范围、置顶、已读）
- `ClassInfo` - 班级信息（班名、年级、班主任、学生数、科目）

## 数据持久化

所有数据存储在 App 的 Documents 目录下，数据变化后 0.5 秒自动保存，重启不丢失。

## 运行要求

- macOS 13.0+
- Xcode 14.0+
- iOS 16.0+

## 使用方法

1. 打开 Xcode → File > New > Project > iOS > App
2. Product Name: `ClassTeacherApp`，Interface: SwiftUI，Language: Swift
3. 将本项目所有 `.swift` 文件拖入 Xcode 项目（勾选 Copy items if needed）
4. 删除自动生成的 `ContentView.swift`
5. Cmd+R 运行

## 技术栈

- SwiftUI - 界面框架
- MapKit - 地图
- PhotosUI - 照片选择
- Foundation - 基础工具
- Combine - 数据变化监听（自动保存）
- JSONEncoder/Decoder - 数据序列化
- FileManager - 文件存储
