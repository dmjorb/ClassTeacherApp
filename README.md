# 班主任工作台 - iOS 原生应用

基于 SwiftUI 开发的原生 iOS 班主任工作台应用，**100% 对齐网页版 UI 和功能**。

## 核心特性

- **底部 Tab 栏**：工作台、学生、成绩、我的（4个Tab）
- **工作台首页**：紫色渐变顶部 + 波浪底部 + 8个功能入口
- **学生管理**：按排筛选、橙色风格、电话按钮、#学号格式
- **成绩管理**：考试列表 → 成绩详情两级结构、新建考试、考试类型筛选
- **班级课表**：周视图网格、午休栏、星标标记我的课
- **值日表**：每天不同背景色卡片、成员标签
- **班级相册**：多相册分类、渐变封面、按日期分组
- **发通知/通知记录**：通知发布、置顶、未读标记
- **总分排名**：前三名展示 + 完整排名列表
- **我的页面**：个人信息、数据统计、设置入口
- **数据本地持久化**：所有数据存手机本地，自动保存
- **真实图片**：PhotosPicker 选图，存本地
- **真实地图**：MapKit 地图，学生家庭住址标记

## 页面结构

### Tab 1 - 工作台（首页）
- 紫色渐变顶部（问候语、工作台、班级名、日期）
- 3个数据概览卡片（班级学生、考试、待办）
- 11个功能入口（全部真实跳转/弹窗）：学生名册、成绩管理、座位表、班级课表、值日表、发通知、通知记录（带未读角标）、总分排名、班级相册、分布地图、班级设置
- 值日安排（可切换下一组）
- 今日课程（我的课）
- 今日待办（可勾选、可添加、可删除）

### Tab 2 - 学生
- 顶部问候+班级+日期
- 搜索栏 + 打印按钮（系统打印面板输出名册）+ 添加按钮
- 学生卡片（橙色圆形头像、姓名、#学号、电话、第X组）
- 长按学生卡片可快速拨打学生/家长电话
- 学生详情（基本信息、联系方式可点击拨打、家庭住址、座位宿舍、备注、编辑、删除；编辑后实时刷新）

### Tab 3 - 成绩
- 顶部问候+班级+日期
- 考试列表（类型筛选、科目数、新建按钮）
- 考试类型筛选（全部、单元测、月考、期中考、期末考）
- 考试卡片（类型图标、考试名、科目数）
- 成绩详情（科目选择、统计、成绩列表、录入；清空输入即删除该条成绩）
- 新建考试（名称、类型、日期、科目选择）

### Tab 4 - 我的
- 个人信息卡片（头像、姓名、班级）
- 数据统计（学生、考试、成绩、通知、照片、待办）
- 数据管理（导出 JSON 备份、导入 JSON 备份、恢复示例数据）
- 功能列表（设置、清除所有数据、关于）

### 功能页面
- **座位表**：7排×5列教室布局、讲台、点击空位安排学生、点击已占座位可移出、自动排座
- **班级课表**：周视图网格、8节课、科目颜色、点击格子添加/编辑/删除课程
- **值日表**：当前值日组、组列表、成员多选、长按删除组
- **发通知/通知记录**：标题、内容、接收范围、发布；记录支持置顶、未读标记、详情、滑动删除
- **总分排名**：考试选择、前三名领奖台、完整排名列表
- **班级相册**：多相册、新建/删除相册、PhotosPicker 选真实照片（本地存储）、照片详情、备注、删除
- **分布地图**：MapKit 真实地图、CLGeocoder 逐个解析学生住址、落标记、进度与失败提示（需联网）
- **班级设置**：班级名、年级、班主任、开设科目管理

## 数据模型

- `Student` - 学生（姓名、学号、性别、电话、家长电话、住址、小组、座位行/列、宿舍、备注）
- `Exam` - 考试（名称、类型、日期、科目列表）
- `ScoreRecord` - 成绩记录（学生、科目、关联考试、分数、满分）
- `Course` - 课程（科目、星期、节次、教室、老师）
- `DutyGroup` - 值日组（组号、成员ID列表）
- `TodoItem` - 待办事项（标题、完成状态）
- `NotificationItem` - 通知（标题、内容、日期、接收范围、置顶、已读）
- `AlbumFolder` - 相册（名称、分类、置顶、照片ID列表）
- `AlbumPhoto` - 照片（关联相册、标题、日期、备注；图片二进制按 ID 存 Documents/Photos）
- `ClassInfo` - 班级信息（班名、年级、班主任、开设科目）
- `AllDataBackup` - 全量备份（导出/导入 JSON，含全部数据和照片）

## 数据持久化

所有数据存储在 App 的 Documents 目录下，数据变化后 0.5 秒自动保存，重启不丢失。

## 运行要求

- macOS 13.0+
- Xcode 14.0+
- iOS 16.0+

## 使用方法

1. 打开 Xcode → File > New > Project > iOS > App
2. Product Name: `ClassTeacherApp`，Interface: SwiftUI，Language: Swift
3. 将本项目所有 `.swift` 文件拖入 Xcode 项目（勾选 Copy items if needed）
4. 删除自动生成的 `ContentView.swift`
5. Cmd+R 运行

## 技术栈

- SwiftUI - 界面框架
- MapKit - 地图
- PhotosUI - 照片选择
- Foundation - 基础工具
- Combine - 数据变化监听（自动保存）
- JSONEncoder/Decoder - 数据序列化
- FileManager - 文件存储
